# MARINT — Application

Vite + React + TypeScript + Tailwind v4 + MapLibre GL. No external tile provider or API key required — the operational map renders entirely from local GeoJSON.

## Run

For a live-editable session:

```
npm install
npm run dev
```

For the jury demo, prefer the production build — one less moving part on the day:

```
npm run build
npm run preview
```

Either way, open `/` for the public homepage or `/operations` for the operational map. The app makes zero external network requests at runtime (map tiles, fonts, and all demo data are served locally) — it works fully offline once `npm install` has completed.

## Vendored MapLibre worker files

`public/maplibre/maplibre-gl-worker.mjs` and `maplibre-gl-shared.mjs` are copied verbatim from `node_modules/maplibre-gl/dist/`. MapLibre's own worker-URL auto-detection doesn't survive Vite's production bundling (the worker chunk either isn't emitted, or its internal relative import 404s) — serving these two files from a stable, unhashed path and pointing `config.WORKER_URL` at them (see `src/components/map/MapView.tsx`) sidesteps that entirely, in both dev and prod. **If `maplibre-gl` is ever upgraded, re-copy both files.**

## Data pipeline

The app reads static JSON/GeoJSON from `public/data/`. It is generated by two scripts (not part of the app bundle):

- `../_tools/geo/process.mjs` — converts the Natural Earth shapefiles in `../Map Assets/Geography/Raw` into the clipped Caspian GeoJSON layers under `../Map Assets/Geography/Processed`.
- `../_tools/data/generate.mjs` — generates the synthetic vessel fleet, AIS tracks, and intelligence-scenario events (`vessels.json`, `tracks.json`, `events.json`, `ports.json`).

Re-run either with `node <script>.mjs` from its own directory, then re-copy the outputs into `public/data/` (see `../Info/DATA_SOURCES.md` for what's real vs. synthetic).

## Structure

- `src/pages/Home.tsx` — public homepage
- `src/pages/Operations.tsx` — operational map (map + sidebar + vessel panel)
- `src/components/map/` — MapLibre view, icons, controls, legend, stats
- `src/components/panels/` — vessel list, alerts, vessel profile, investigation timeline
- `src/lib/store.ts` — app state (zustand)
